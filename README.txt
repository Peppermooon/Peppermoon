PEPPERMOON COMMUNITY V1

WHAT IS INCLUDED
- New Community page
- Anyone can read community posts without login
- Google/login required only to create a post
- Post types:
  Discussion, Review, Question, Recommendation, Theory, News / Update
- Categories:
  Gaming, Movies, TV Series
- Optional image upload
- Separate community-images bucket
- User can edit/delete only their own posts
- Admin can delete/moderate any post
- Official articles remain completely separate
- Create Post link from the user menu now opens the community creator
- Clicking outside the Create Post form does NOT close it

NOT YET INCLUDED
- Comments/replies
- Likes
- Saves
Those buttons are visible as placeholders and are the next version.

SETUP
1. In Supabase, open SQL Editor > New query.
2. Run SUPABASE-COMMUNITY-SETUP.sql.
3. Upload all website files to the root of the GitHub repository.
4. Open community.html.
5. Test reading while logged out.
6. Login with Google and create a test post.
7. Test edit/delete with the same user.
