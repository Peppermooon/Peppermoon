PEPPERMOON SUPABASE CMS

Upload ALL files in this folder to the root of your GitHub repository.

New files:
- admin.html : admin login and article manager
- article.html : public dynamic article page
- favicon.png : browser tab icon

Admin use:
1. Open yourwebsite/admin.html
2. Login with the Supabase user you created.
3. Click + New Article.
4. Add title, category, summary, article text, and optional image.
5. Choose Draft or Published.
6. Tick Show on homepage if needed.
7. Save.

Published articles load automatically on Home/Gaming/Movies/TV/Trending pages.
